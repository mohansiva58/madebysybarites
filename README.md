## ✦ Getting Started

### Prerequisites

- Node.js 18+
- pnpm
- Git

### Clone

```bash
git clone https://github.com/mohansiva58/madebysybarites.git
cd madebysybarites
```

### Install

```bash
pnpm install
```

### Development

```bash
pnpm dev
```

Open `http://localhost:3000`.

### Production

```bash
pnpm build
pnpm start
```
